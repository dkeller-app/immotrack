Maquette : carte « Stockage de cet appareil »

Maquette statique (aucun code applicatif touché). La carte remplace la ligne « Taille base de données — N KB / ~10 MB » de la carte « Statistiques base », dont les compteurs (Mouvements, Logements…) restent. Elle est montrée pour les 5 états de la ligne « Copie hors ligne », en téléphone, tablette et PC, en thème clair puis sombre, puis avec les trois messages (toasts) T1 à T3. Tokens et classes recopiés de css/main.css.

Conformité charte : line-icons SVG currentColor à la place des emoji (M-9), registre neutre sans tutoiement (M-13), pas de rouge ni d'orange : corail pour l'alerte, vert pour le positif, neutre pour le reste (M-15), pastilles à 13 px (M-17). Le texte des pastilles corail reste en encre (--t1) sur fond corail teinté : le corail en texte fin n'atteint pas 4,5:1. Les couleurs de toast de la maquette sont une proposition : le #toast actuel colore tout le texte (var(--ora) / var(--red)).

Thème clair

A. À jour

B. Mode réduit

C. Pas à jour depuis le 06/10 à 14:32

D. Incomplète

E. Base de test (sandbox)

Page Réglages en PC (1280 px), état A

Messages (toasts)

T1 — En ligne, copie locale non mise à jour (neutre, icône corail, une fois par session)

T2 — Hors ligne, stockage plein (alerte corail)

T3 — Sandbox, stockage plein (alerte corail)

Avant / après — T1

Avant (en ligne, alors que le cloud avait reçu la modification)
« ⚠️ Mémoire pleine : cette modification n'est PAS enregistrée sur cet appareil. Libère de l'espace, puis reprends. »
Après (T1, neutre, icône corail, une fois par session)
Copie de secours de cet appareil non mise à jour. La modification est bien enregistrée dans le cloud ; sans réseau, cet appareil afficherait des données plus anciennes. Détail : Réglages → Stockage de cet appareil.

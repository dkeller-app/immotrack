🔓 Déchiffrer une sauvegarde Propryo

Outil autonome et hors ligne. Rien n'est envoyé sur Internet — tout se passe dans votre navigateur.

Comment ça marche — cet outil retrouve le fichier .zip d'origine à partir de votre .enc et du mot de passe, puis vous le fait télécharger. Vous ouvrez ensuite le .zip avec n'importe quel outil.

Mot de passe oublié = données irrécupérables. Il n'existe aucune porte dérobée : le chiffrement est AES-256-GCM, la clé dérivée de votre mot de passe par PBKDF2-SHA256. Conservez ce fichier HTML avec vos sauvegardes : il fonctionne même sans l'application, hors ligne, indéfiniment.

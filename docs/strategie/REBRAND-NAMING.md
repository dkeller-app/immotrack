# Changement de nom ImmoTrack — Brief & méthode

**Décision prise 2026-06-15 : on change de nom avant le lancement public.**

---

## 1. Pourquoi on change

Le nom « ImmoTrack » est occupé par 3 acteurs dans l'immobilier / proptech :

| Collision | Qui | Statut |
|---|---|---|
| **immotrack.fr** | Site français « Carte 3D des prix immobiliers + cadastre » | Actif, secteur immo |
| **immotrack.com** | **ImmoTrack AG** — société suisse de Zurich, fondée 2014 par Ofer Becker, logiciel de facility management immobilier | Société établie depuis 12 ans, vrai produit |
| **Google Play** | App « ImmoTrack » (`com.immo.track`) | Déjà publiée |

**5 raisons bloquantes :**
1. **Domaine** : ni .com ni .fr disponibles → coincé sur un TLD secondaire peu crédible.
2. **Marque** : société suisse de 2014 a très probablement protégé « ImmoTrack » (Suisse + possiblement EUIPO qui couvre la France) → risque d'opposition en pleine croissance.
3. **SEO** : impossible de ranker « ImmoTrack » avec 3 acteurs immo dessus. La stratégie SEO est sabotée à la racine.
4. **App stores** : nom déjà pris sur Play Store → la V1.1 Capacitor ne pourrait pas s'appeler ImmoTrack.
5. **Crédibilité** : un investisseur / CGP qui google « ImmoTrack » tombe sur le concurrent suisse.

**Le bon timing** : aucune notoriété publique acquise. Le nom n'existe que dans le code et les docs internes. Renommer maintenant = quelques heures. Renommer après le 14 octobre = perdre le SEO, embrouiller les clients, refaire tous les supports, risquer le conflit de marque en pleine traction.

## 2. La stratégie de naming : brandable, pas descriptif

**Erreur à éviter** : chercher un nom descriptif type « immo + X », « loca + X », « bail + X ».
- Tous pris (Qalimo, Rentila, Loximo, ImmobilierLoyer, LOCKimmo, BailFacile, Gererseul…).
- Génériques → impossible à protéger en marque.
- Mauvais pour le SEO (on se bat contre tout le secteur sur des mots communs).

**Stratégie retenue** : un nom **brandable** — court (1-3 syllabes), mémorable, prononçable en français, qui ne décrit pas le métier mais qui DEVIENT la marque.

Référence : les meilleurs SaaS français récents ne décrivent jamais leur métier.
- **Qonto** (banque pro) — ne dit pas « banque »
- **Pennylane** (comptabilité) — ne dit pas « compta »
- **Swile** (titres-resto) — ne dit pas « repas »
- **Alma** (paiement fractionné) — ne dit pas « crédit »
- **Spendesk**, **Pumpkin**, **Lydia**, **Shine** — idem

Un nom brandable :
- Se protège facilement en marque (distinctif).
- Rank en SEO sans concurrence (personne d'autre dessus).
- Crée une identité propre, pas une commodité.

## 3. Les 5 critères de validation (tous obligatoires)

Un nom n'est retenu QUE s'il coche les 5 :

1. **Domaine .fr ET .com disponibles** (ou .fr + .app si .com vraiment pris). Vérif : whois sur gandi.net ou ovh.com/fr/domaines.
2. **Pas de marque déposée conflictuelle** en France (INPI) ni UE (EUIPO), dans les classes 9 (logiciels), 36 (immobilier/financier), 42 (SaaS). Vérif : data.inpi.fr + euipo.europa.eu/eSearch.
3. **Nom libre sur les app stores** (Play Store + App Store). Vérif : recherche directe.
4. **Handles réseaux disponibles** (au moins LinkedIn + Instagram + un sur X). Vérif : namecheckr.com.
5. **Prononçable et mémorable** en français, pas de connotation négative, pas d'homophone gênant.

## 4. Directions de naming proposées

> Pistes illustratives pour lancer la réflexion. **Aucune n'est validée** — chacune doit passer les 5 critères. Le goût final t'appartient.

### Direction A — Évocation de la confiance / protection des données
Cohérent avec ton pitch souverain (RLS, immutabilité, hébergement EU).
- **Capsa** (latin : coffre, écrin → « vos données en sécurité »)
- **Bastio** (de bastion → protection)
- **Klovis** / **Clovis** (consonance française historique, solide)
- **Teno** (de « tenir » → maîtrise, garde)

### Direction B — Évocation du patrimoine / sérénité
Cohérent avec la cible SCI familiale + CGP.
- **Patrio** (patrimoine, court)
- **Sereo** / **Séréo** (sérénité)
- **Foncea** (foncier, élégant)
- **Soclo** (socle → fondation patrimoniale)

### Direction C — Brandable pur (abstrait, type Qonto)
Le nom devient la marque, sans évocation directe.
- **Keaz**
- **Loyz** (clin d'œil discret à « loyer » sans être descriptif)
- **Rendo** (clin d'œil à « rendement / rendre »)
- **Mako** / **Nabo** / **Velio** (sonorités franches, brandables)

### Direction D — Évocation du pilotage / vigilance
Cohérent avec ton dashboard « Pilotage » et les alertes (IRL, DPE).
- **Vigia** (de vigie → l'outil qui veille pour vous)
- **Capen** (cap → direction)
- **Pilo** (pilotage)

## 5. Méthode pour trancher (session dédiée)

1. **Génération large** : produire 40-50 candidats sur les 4 directions.
2. **Premier filtre — domaines** : tester .fr + .com de chaque candidat (whois). Élimine ~70 %.
3. **Deuxième filtre — marque** : sur les survivants, vérif INPI + EUIPO classes 9/36/42. Élimine les conflits.
4. **Troisième filtre — stores + réseaux** : Play Store, App Store, handles sociaux.
5. **Shortlist finale** : 3-5 noms qui cochent les 5 critères.
6. **Test utilisateur** : faire prononcer / épeler / mémoriser à 5 personnes (bailleurs, si possible).
7. **Décision** + **dépôt immédiat** : acheter les domaines (.fr + .com) ET déposer la marque INPI (~250 € pour 1 classe, ~750 € pour 3 classes) AVANT toute communication publique.

⚠️ **Ne jamais communiquer publiquement le nom avant d'avoir sécurisé domaines + dépôt marque.** Sinon un squatteur peut déposer avant toi.

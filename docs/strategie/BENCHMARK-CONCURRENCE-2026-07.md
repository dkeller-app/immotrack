## 4. Lectures transverses (faits)

1. **Aucun acteur B2C pur n'a de levée VC significative active** — Rentila, Qalimo, Gérer Seul, Smartloc, ImmobilierLoyer = tous bootstrap. Seul **Smovin** (VC ~1,4 M€) et il est **déficitaire/fonds propres négatifs**. → un SaaS gestion locative B2C FR **peut être rentable sans levée** (Smartloc RN +141 k€, ImmobilierLoyer RN +177 k€, LOCKimmo +438 k€ le prouvent).
2. **Opacité financière quasi-totale côté B2C** : CA non publiés (petites SAS confidentielles). Les seuls CA exploitables : Smartloc 761 k€, Smovin 889 k€, LOCKimmo 1,79 M€, Vilogi RN seul, Manda ex-Hello Syndic 4,34 M€.
3. **Argent et M&A concentrés côté B2B/consolidation** : Septeo (420 M€, valo 3,5 Md€), Manda (64 M€ Naxicap, roll-up), Vilogi (build-up MIP/AGLI), Indy (86 M€) — pas côté B2C particulier.
4. **Course à l'IA généralisée 2025-2026** : Rentila (assistant), BailFacile (clauses), LOCKimmo (annonces), Vilogi (agent + EDL photo), Qalimo (rapprochement auto). L'IA n'est plus un différenciant, c'est une commodité en cours.
5. **Cible fiscale 2044 nu confirmée peu couverte** : 1 seul frontal exact (Déclaration-Foncier.fr, micro-structure fragile) + 1 élargi (Ownily via SCI). Indy/Qlower sont adjacents (LMNP/SCI/BIC). → le créneau reste défendable.
